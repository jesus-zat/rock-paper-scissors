# Rock Paper Scissors

## Description

This is a Rock Paper Scissors game built with JavaScript as part of The Odin Project Foundations course.

The game is played through the browser console and consists of five rounds against the computer. The computer randomly chooses Rock, Paper, or Scissors, while the player enters their choice through a prompt.

## Features

- Player can choose Rock, Paper, or Scissors.
- Computer generates a random choice.
- Each round determines the winner.
- The game keeps track of the player and computer scores.
- The game consists of five rounds.
- A final winner is declared at the end.
- Player input is case-insensitive.

## Technologies

- HTML
- JavaScript
- Git
- GitHub

## How to run

1. Clone this repository.
2. Open the project in your code editor.
3. Open `index.html` in your browser.
4. Open the browser developer console.
5. Enter Rock, Paper, or Scissors when prompted.
